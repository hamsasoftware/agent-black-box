We are moving shipcalc from grams to kilograms. Weights are currently whole grams (ints) all over the package; the public API and the internal storage must switch to kilograms written as decimal strings. The contract is three pages: `docs/MIGRATION.md` (the representation, rounding, how invalid input is reported, the renamed API, the formats that must stay in grams, the other call sites, and the housekeeping: version and changelog), `docs/ROUNDING.md` (the quantities the package computes from a weight, with their rounding and boundaries) and `docs/FORMATS.md` (data files, imports and logs, and how old data must still be read). Read all three; together they are the contract.

CI runs `python -m unittest`. The tests in `tests/` already use the new API and currently fail, and the docstring examples that `tests/test_doctests.py` runs will need to follow; I need everything green, and I need the rest of the package, its shipped data files and its generator to follow the pages too, not only the parts the tests touch.
